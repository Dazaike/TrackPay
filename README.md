# TrackPay

> Your shift, priced by the second.

A local-first Android app built with Kotlin, Jetpack Compose, and Material 3. Track live earnings as you work, allocate pay to savings goals, and analyze shift insights—no accounts, no cloud, no subscriptions.

## Features

- **Live Pay Timer**: Track real-time earnings on screen or via ongoing notifications.
- **Jobs & Overtime**: Multi-job support with custom hourly rates, overtime rules, and colors.
- **Savings Goals**: Set target goals with automated earnings allocations.
- **Insights & Streaks**: Track shift trends, best weekdays, challenges, and achievements.
- **Local & Private**: 100% local-first data storage with optional geofence suggestions.

## Build & Run

Requires JDK 17+ and Android SDK 35.

```bash
# Debug APK
./gradlew :app:assembleDebug

# Release APK
./gradlew :app:assembleRelease
```
